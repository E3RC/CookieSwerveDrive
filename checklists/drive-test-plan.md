# Drive Test Plan

## Test sequence

Do not skip directly to full-speed driving.

1. Mechanical bench inspection
2. Robot on blocks
3. Low-speed forward and reverse
4. Low-speed strafe
5. Low-speed rotation
6. Figure-eight driving
7. 25 percent speed test
8. 50 percent speed test
9. Full-speed validation
10. Post-test inspection

## Bench tests

- Hand rotate each steering module
- Compare steering friction across all four modules
- Hand spin each wheel
- Check for rubbing
- Check drive shaft endplay
- Check shoulder bolts
- Check cone-to-94T screw tension
- Check bevel gear mesh
- Grease gears

## Robot on blocks

- Command each drive motor individually
- Command each steer motor individually
- Confirm drive direction
- Confirm steer direction
- Confirm encoder value changes correctly
- Watch for oscillation
- Watch current draw
- Stop immediately if binding occurs

## Floor tests

- Low-speed forward
- Low-speed reverse
- Low-speed strafe left
- Low-speed strafe right
- Low-speed rotate clockwise
- Low-speed rotate counterclockwise
- Figure-eight driving
- Direction changes

## Inspection after each session

- Check critical fastener paint marks
- Check drive shaft retention
- Check wheel shoulder bolts
- Check bearing seating
- Check bevel gear wear pattern
- Check printed parts for cracks
- Check for plastic dust
- Check motor and controller temperatures
- Log issues before continuing

# Subassembly QC Checklist

Use this checklist after each subassembly batch.

## Wheel subassemblies

- Hub halves seated correctly
- Tread seated correctly
- Wheel bevel gear seated flat
- Wheel screws snug and even
- Bearings fully seated
- Wheel spins freely
- No visible wobble

## Housing lid subassemblies

- Threaded inserts installed straight
- Threaded inserts flush
- Screws thread cleanly into inserts
- No melted plastic blocking mating surfaces

## Steer gear subassemblies

- Bearing fully seated
- Gear teeth clean
- Spacers installed in correct order
- Drive gear installed
- Encoder bridge secure
- Gear stack does not bind

## Steer motor subassemblies

- Pinion pressed on straight
- Motor plate installed correctly
- UltraPlanetary stages installed in correct order
- Output assembly rotates smoothly
- Steer shaft installed
- Set screws tight
- Guard decision applied consistently

## Drive motor subassemblies

- Vortex motor mount installed
- Spark Flex attached
- REV Through Bore Encoder installed
- Encoder clears rotating parts
- Wires routed safely
- Module assignment labeled

## Housing subassemblies

- Housing bearing seated
- Bearing grooves cleaned
- Delrin balls travel freely
- Ring shields installed

## Cone subassemblies

- Cone bearing seated
- Axle holes clear
- Bearing grooves cleaned
- Delrin balls travel freely
- No cracks or layer separation

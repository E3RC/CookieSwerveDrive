# Final Assembly QC Checklist

Use this checklist for each completed module.

## Module identification

- Module ID labeled: FL / FR / RL / RR
- Module type labeled: A / B
- Drive motor CAN ID recorded
- Steer motor CAN ID recorded
- Encoder ID or input recorded
- Assembler recorded
- Inspector recorded

## Mechanical checks

- First Delrin ball race loaded with 52 balls
- Second Delrin ball race loaded with 52 balls
- Cone rotates smoothly
- 94T gear rotates smoothly
- Cone-to-94T screws adjusted evenly
- Wheel spins freely
- No wheel rub
- Bevel gears mesh smoothly
- Drive shaft has no meaningful up/down slack
- Shoulder bolt installed and backed off correctly
- Dust shields installed
- Housing lid fully seated
- Threaded inserts not pulled out
- All visible fasteners checked
- Critical fasteners paint-marked

## Drive stack verification

- Correct 2026 drive gear path installed
- 12T drive gear verified
- 15T bevel gear verified
- 32T driven gear verified
- 45T bevel gear verified
- Shaft orientation verified
- Spacers installed in correct order

## Motor and encoder checks

- NEO Vortex installed
- Spark Flex attached
- REV Through Bore Encoder installed
- Encoder clears shaft
- NEO 550 steer motor installed
- Spark MAX installed or assigned
- UltraPlanetary stack rotates smoothly
- Steer pinion installed correctly

## Electrical readiness

- Wires labeled
- Connectors installed
- No exposed conductor
- CAN path planned
- Strain relief planned
- Encoder cable path planned

## Pass/fail

- Pass mechanical inspection
- Pass electrical inspection
- Rework required
- Notes recorded

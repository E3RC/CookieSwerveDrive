# Failure and Rework Log

Use this log for build defects, test failures, and design notes.

| Date | Module | Area | Issue | Suspected cause | Fix attempted | Result | Owner | Follow-up needed |
|---|---|---|---|---|---|---|---|---|
|  | FL / FR / RL / RR | Mechanical / Electrical / Software / Print / BOM |  |  |  |  |  |  |

## Failure categories

- Print defect
- Bearing fit
- Gear mesh
- Shaft retention
- Wheel retention
- Steering friction
- Encoder issue
- CAN issue
- Wiring issue
- Software/configuration issue
- Fastener issue
- Unknown

## Required photos

For mechanical failures, take photos of:

- Whole module
- Failed part
- Adjacent parts
- Fastener state
- Gear wear pattern
- Printed layer failure, if any

## Rework rule

Do not return a module to service until the issue, fix, and verification test are recorded.
